## 7. Bottom sheets

If you want to implement a bottom sheet, you can use the
`ModalBottomSheet` composable.

### Esempio Jetpack Compose
```kotlin
ModalBottomSheet(onDismissRequest = { /* Executed when the sheet is dismissed */ }) {
    // Sheet content
}
```
